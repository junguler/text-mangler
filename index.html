AI assist: getting started

 

  
Optional. Every tab works without it. A small language model runs inside your browser and redoes the current setting; nothing is uploaded.

  
Quick start

  
  1. Download one model file (see below), once.
  2. Tick AI assist, press Load .gguf and pick the file, or drop it on the AI panel.
  3. Type or paste text, then press Run AI. The local result stays live meanwhile.

  
Which model?

  
    
   
  • LFM2.5-350M Q4_K_M, 229 MB. Suggested first pick: newest, small and quick. files
    • 
   
  • LFM2-350M Q4_K_M, 229 MB. Previous generation, also works. files
    • 
   
  • Qwen3-0.6B Q4_K_M, 397 MB. Follows instructions more closely, roughly half the speed. files
    • 
   
  • SmolLM2-360M-Instruct Q8_0, 386 MB. Fully open fallback. files
    • 
  

  
Prefer Q4_K_M; avoid IQ quants (slow in WebAssembly). Memory needed is about the file size plus 300 MB.

  
Engine, Context and WebGPU are under Settings and details on the AI panel. The defaults work for most people.
